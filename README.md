# Change Detection Task Demo

The change-detection task is a visual working memory paradigm, where subjects are shown an array of items (e.g. coloured squares) for a brief amount of time. After a short delay, their working memory is tested by showing an item either unchanged (e.g. the same coloured square) or changed (e.g. a different coloured square). Change-detection performance is pretty accurate up to around 4 items, where performance starts to drop – this is indicative of a working memory capacity limit.

This demo is hosted at williamngiam.github.io/ChangeDetectionDemo and provided for educational purposes. For example, this task can be embedded using an iframe into course pages or other websites.

The task was written in jsPsych (v8) using their existing plug-ins. The task script (`changeDetection.js`) controls the demo and can be readily updated to create variants of the change-detection task.
